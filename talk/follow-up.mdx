첫 답이 마음에 안 드는 것은 **아주 정상입니다.** AI와 대화는 한 번에 끝내는 것이 아니라 **주고받으면서 다듬는 것**입니다.

## 이어서 고쳐 달라고 하기

AI는 같은 대화 안에서 앞의 내용을 기억합니다. 그래서 처음부터 다시 설명하지 말고 **바꾸고 싶은 점만** 말하면 됩니다.

[앞 페이지](/talk/asking-well)에서 받은 여행지 추천에 이어서 이렇게 보냈습니다.

```text
좋아요. 이 중 두 번째 곳으로 정했어요. 부모님께 보낼 카톡 메시지로 세 줄 이내로 짧게 바꿔 주세요.
```

## 바로 쓰는 고쳐 달라는 말

| 이럴 때 | 이렇게 말하세요 |
|---|---|
| 너무 길어요 | "세 줄로 줄여 주세요", "핵심만 알려 주세요" |
| 너무 어려워요 | "초등학생도 알아듣게 다시 설명해 주세요" |
| 너무 딱딱해요 | "친구에게 말하듯 편하게 바꿔 주세요" |
| 너무 가벼워요 | "회사 윗분께 보내는 글처럼 정중하게 바꿔 주세요" |
| 감이 안 와요 | "예를 들어 주세요" |
| 정리가 안 돼요 | "표로 정리해 주세요", "번호를 매겨 주세요" |
| 다른 게 보고 싶어요 | "다른 방향으로 세 가지 더 알려 주세요" |
| 일부만 바꾸고 싶어요 | "두 번째 문장만 더 짧게 해 주세요" |

## 답 다시 만들기 버튼

답 아래의 **동그란 화살표** 버튼을 누르면 같은 질문으로 답을 새로 만듭니다. 질문을 바꾸지 않고 다른 답을 보고 싶을 때 씁니다.

- 그림이나 문구처럼 **정답이 없는 것**을 여러 개 받아 보고 싶을 때 좋습니다
- 답이 이상하게 끊겼을 때도 씁니다

<Tip>
  다시 만들기를 여러 번 눌러도 마음에 안 들면 버튼보다 **말로 고쳐 달라고 하는 것**이 빠릅니다. 무엇이 마음에 안 드는지 알려 주면 그 방향으로 바뀝니다.
</Tip>

## 틀렸다고 알려 주기

AI가 틀린 말을 했다면 그냥 알려 주면 됩니다.

```text
강릉역에서 경포호까지는 걸어서 가기 어려운 거리예요. 택시나 버스로 가는 방법으로 다시 알려 주세요.
```

AI는 대개 사과하고 고친 답을 줍니다. 다만 **고친 답도 틀릴 수 있으니** 중요한 정보는 따로 확인하세요.

## 대화가 꼬였을 때는 새로 시작하기

이런 경우에는 이어서 고치기보다 **새 채팅**을 여는 편이 낫습니다.

- 여러 번 고쳐 달라고 했는데 계속 같은 실수를 합니다
- 전혀 다른 주제로 넘어갑니다
- 대화가 너무 길어져서 앞의 내용을 자꾸 잊습니다

새 채팅을 열 때는 **지금까지 정한 내용을 한 번에 정리해서** 첫 질문에 넣으면 됩니다.

```text
70대 부모님과 11월 초 1박 2일 강릉 여행을 가요. KTX로 가고, 오래 걷는 일정은 빼 주세요.
첫날과 둘째 날 일정을 시간대별로 짜 주세요.
```

## 직접 해 보기

아무 질문이나 하나 보낸 뒤, 위 표의 말을 **세 번 연속** 써 보세요. 예를 들어 "예를 들어 주세요" → "표로 정리해 주세요" → "세 줄로 줄여 주세요". 같은 내용이 어떻게 바뀌는지 볼 수 있습니다.
