상황별로 바로 쓸 수 있는 질문을 모았습니다. **괄호 안의 내용만 내 상황에 맞게 바꿔서** 쓰세요. 코드 상자 오른쪽 위의 복사 버튼을 누르면 한 번에 복사됩니다.

<Tip>
  이 질문들은 **출발점**입니다. 답을 받은 뒤 [답이 마음에 안 들 때](/talk/follow-up)에서 배운 대로 고쳐 달라고 하면 더 좋아집니다.
</Tip>

## 글쓰기

```text title="정중한 거절" wrap
(누구)에게 (무엇)을 정중하게 거절하는 문자를 써 주세요. 관계가 상하지 않게, 세 줄 이내로요.
```

```text title="사과 메시지" wrap
(상황)에 대해 (누구)에게 사과하는 메시지를 써 주세요. 변명은 빼고, 진심이 느껴지게 짧게요.
```

```text title="맞춤법만 고치기" wrap
아래 글의 맞춤법과 띄어쓰기만 고쳐 주세요. 내용과 말투는 절대 바꾸지 마세요.

(글 붙여 넣기)
```

```text title="말투 바꾸기" wrap
아래 글을 (회사 윗분께 보내는 / 친구에게 보내는 / 어르신께 드리는) 말투로 바꿔 주세요.

(글 붙여 넣기)
```

## 요약과 번역

```text title="세 줄 요약" wrap
아래 글을 세 줄로 요약해 주세요. 마지막 줄에는 저에게 어떤 영향이 있는지 써 주세요.

(글 붙여 넣기)
```

```text title="할 일만 뽑기" wrap
아래 안내문에서 제가 해야 할 일과 기한만 목록으로 뽑아 주세요.

(안내문 붙여 넣기)
```

```text title="자연스러운 번역" wrap
아래 (영어/일본어/중국어) 글을 자연스러운 우리말로 번역해 주세요. 어려운 단어는 따로 뜻을 알려 주세요.

(글 붙여 넣기)
```

## 배우기

```text title="쉽게 설명" wrap
(모르는 개념)을 (초등학생 / 중학생 / 처음 듣는 사람)도 알아듣게 설명해 주세요. 비유를 하나 들어 주세요.
```

```text title="한 문제씩 퀴즈" wrap
(주제)로 퀴즈 5문제를 내 주세요. 한 문제씩 내고, 제가 답하면 맞았는지와 해설을 알려 주세요.
```

```text title="학습 계획" wrap
저는 (나이/수준)이고 (배우고 싶은 것)을 배우고 싶어요. 하루 (시간)씩 (기간) 동안 배울 계획을 짜 주세요.
```

## 생활

```text title="냉장고 요리" wrap
냉장고에 (재료들)이 있어요. (시간) 안에 만들 수 있는 (반찬/요리) 두 가지를 재료와 순서만 간단히 알려 주세요.
```

```text title="여행 일정" wrap
(누구)와 (언제) (어디)로 (기간) 여행을 가요. (조건: 예산, 체력, 교통편). 일정을 시간대별 표로 짜 주세요.
```

```text title="선물 추천" wrap
(누구)에게 줄 (어떤 날) 선물을 (예산) 안쪽으로 다섯 가지 추천해 주세요. 그분은 (취미/특징).
```

```text title="병원 가기 전 질문 목록" wrap
(증상)이 있어서 병원에 가요. 의사 선생님께 물어볼 질문 목록을 만들어 주세요. 진단은 하지 말아 주세요.
```

## 일

```text title="회의 정리" wrap
아래 회의 메모를 1. 결정된 것 2. 할 일(누가, 언제까지) 3. 다음에 논의할 것 순서로 정리해 주세요.

(메모 붙여 넣기)
```

```text title="엑셀 함수" wrap
엑셀에서 (A열에 무엇, B열에 무엇)이 있어요. (원하는 결과)를 구하는 함수를 알려 주세요. 입력하는 방법도 초보자에게 설명하듯 알려 주세요.
```

```text title="목차부터 받기" wrap
(문서 종류)를 쓰려고 해요. 주제는 (주제)예요. 바로 쓰지 말고 목차와 각 항목에 들어갈 내용을 한두 줄씩 먼저 제안해 주세요.
```

## 안전하게 쓰기

```text title="확인 요청" wrap
방금 답에 틀린 내용이 없는지 다시 확인해 주세요. 확실하지 않은 부분은 표시해 주세요.
```

```text title="출처 요청" wrap
방금 알려 준 내용의 출처를 알려 주세요. 정부나 공공기관 자료가 있다면 그걸 우선해 주세요.
```

```text title="사기 확인" wrap
아래 메시지가 사기일 가능성이 있나요? 의심스러운 부분과 확인하는 방법을 알려 주세요.

(메시지 붙여 넣기)
```

```text title="유료 강의 점검" wrap
아래는 유료 AI 강의 목차예요. 이 내용을 무료로 배울 수 있는 방법이 있나요? 무료로 배우기 어려운 부분이 있다면 무엇인가요?

(목차 붙여 넣기)
```
