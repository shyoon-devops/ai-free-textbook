[상황 알려 주기](/skills/give-context)에서 내 상황을 알려 주면 답이 좋아진다고 배웠습니다. 그런데 매번 "저는 55세이고 무릎이 약해요"라고 쓰기는 번거롭습니다. 이럴 때 쓰는 기능이 **맞춤 설정**, **기억**, **프로젝트**입니다.

<Note>
  이 페이지의 기능은 모두 **로그인해야** 쓸 수 있습니다. 메뉴 이름은 서비스마다 다르고 자주 바뀝니다. 2026년 9월 기준입니다.
</Note>

## 세 가지 기능 한눈에 보기

| 기능 | 하는 일 | 이럴 때 좋습니다 |
|---|---|---|
| **맞춤 설정** | 모든 대화에 적용할 "나에 대한 설명"과 "답변 방식"을 적어 둡니다 | 항상 같은 조건을 원할 때 |
| **기억** | 대화하면서 알게 된 내 정보를 AI가 스스로 기억합니다 | 따로 적지 않아도 알아서 기억하게 하고 싶을 때 |
| **프로젝트** | 주제별로 대화와 파일을 한 폴더에 모아 둡니다 | 한 가지 일을 여러 번에 걸쳐 할 때 |

## 맞춤 설정: 나에 대해 한 번만 알려 주기

설정 메뉴에서 **맞춤 설정**, **개인 맞춤**, **지침** 같은 항목을 찾으세요. 두 가지를 적을 수 있는 경우가 많습니다.

<Steps>
  <Step title="나에 대해 적기">
    AI가 알았으면 하는 내 상황을 적습니다.

    ```text wrap
    저는 60대이고 컴퓨터를 잘 다루지 못합니다. 서울에 삽니다. 손주가 둘 있습니다.
    ```
  </Step>
  <Step title="원하는 답변 방식 적기">
    항상 이렇게 답해 줬으면 하는 방식을 적습니다.

    ```text wrap
    어려운 말은 쓰지 말고 쉽게 설명해 주세요.
    답은 짧게, 중요한 것부터 말해 주세요.
    확실하지 않은 내용은 "확실하지 않음"이라고 표시해 주세요.
    ```
  </Step>
  <Step title="저장하고 새 대화에서 확인하기">
    저장한 뒤 **새 대화**를 열고 아무 질문이나 해 보세요. 답이 적어 둔 방식대로 나오는지 확인합니다.
  </Step>
</Steps>

<Tip>
  [AI도 거짓말을 합니다](/safety/hallucination)에서 배운 **"확실하지 않으면 표시해 달라"**는 문장을 여기에 적어 두면 매번 쓰지 않아도 됩니다.
</Tip>

## 기억 기능

일부 서비스는 대화 중에 알게 된 정보를 **스스로 기억**합니다. "제 딸 이름은 지수예요"라고 한 번 말하면 다음 대화에서도 기억하는 식입니다.

- **확인하기:** 설정의 **기억** 또는 **저장된 정보** 메뉴에서 AI가 무엇을 기억하고 있는지 볼 수 있습니다
- **지우기:** 잘못 기억했거나 잊게 하고 싶은 것은 그 메뉴에서 지우면 됩니다
- **말로 지우기:** "제 주소를 기억하지 마세요"라고 말해도 됩니다

<Warning>
  기억 기능은 편리하지만, AI가 **무엇을 기억하는지 가끔 확인**하세요. [개인정보](/safety/privacy)가 저장되어 있다면 지우세요.
</Warning>

## 프로젝트: 주제별 폴더 만들기

한 가지 일을 여러 날에 걸쳐 할 때 좋습니다. 서비스에 따라 **프로젝트**, **Gems**, **GPTs** 같은 이름으로 부릅니다.

<CardGroup cols={2}>
  <Card title="자서전 쓰기" icon="book">
    프로젝트에 "제 인생 이야기를 정리하는 중입니다. 따뜻한 말투로 써 주세요"라고 적어 두고, 매일 한 장씩 대화합니다.
  </Card>
  <Card title="가게 운영" icon="store">
    메뉴판과 가격표를 올려 두고, SNS 글이나 손님 답장을 쓸 때마다 이 프로젝트에서 대화합니다.
  </Card>
  <Card title="공부" icon="graduation-cap">
    교재 목차를 올려 두고, 매일 한 단원씩 설명 듣고 퀴즈를 풉니다.
  </Card>
  <Card title="집안 행사" icon="calendar-days">
    칠순 잔치 준비 내용을 모아 두고, 준비할 때마다 이어서 대화합니다.
  </Card>
</CardGroup>

프로젝트를 만드는 방법은 대개 이렇습니다.

1. 왼쪽 메뉴에서 **프로젝트** 또는 **Gems** 같은 항목을 찾아 **새로 만들기**를 누릅니다
2. 이름을 정하고, 이 프로젝트에서 AI가 따라야 할 **지침**을 적습니다
3. 필요한 파일(메뉴판, 목차 등)이 있으면 올립니다
4. 이 프로젝트 안에서 대화를 시작하면 지침과 파일을 알고 답합니다

## 직접 해 보기

지금 쓰는 서비스의 설정에서 **맞춤 설정**을 찾아, 아래 한 줄만 적어 보세요.

```text wrap
어려운 말은 쓰지 말고, 답은 짧게 중요한 것부터 말해 주세요.
```

그리고 새 대화에서 아무 질문이나 해 보고, 답이 짧아졌는지 확인하세요.
