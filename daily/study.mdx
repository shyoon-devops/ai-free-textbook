AI는 **같은 질문을 열 번 해도 싫은 내색을 하지 않는 선생님**입니다. 모르는 말이 나오면 부끄러워하지 말고 물어보세요.

## 어려운 개념 쉽게 설명 듣기

**누구 수준으로 설명해 달라고 할지** 정하면 됩니다. 비유를 들어 달라고 하면 더 쉽게 이해됩니다.

```text wrap
금리가 오르면 왜 대출 이자가 늘어나는지 중학생도 알아듣게 설명해 주세요.
비유를 하나 들어 주고, 다섯 문장 이내로요.
```

설명이 여전히 어렵다면 이어서 이렇게 말하면 됩니다.

- "아직 잘 모르겠어요. 다른 비유로 다시 설명해 주세요"
- "방금 말한 '원금'이 무슨 뜻인가요?"
- "실제 숫자로 예를 들어 주세요"

## 퀴즈로 복습하기

배운 내용을 확인하고 싶을 때는 퀴즈를 내 달라고 하세요.

```text wrap
방금 설명한 내용으로 퀴즈 3문제를 내 주세요. 한 문제씩 내고, 제가 답하면 맞았는지 알려 주세요.
```

**"한 문제씩"**이라고 하면 시험 보듯 주고받을 수 있습니다.

<Warning>
  AI가 낸 퀴즈의 **정답이 틀릴 때가 있습니다.** 보기와 정답 번호가 안 맞는 경우도 실제로 있습니다. 정답이 이상하면 "정답이 맞나요? 다시 확인해 주세요"라고 물어보세요. 실제 사례는 [AI도 거짓말을 합니다](/safety/hallucination)에서 볼 수 있습니다.
</Warning>

## 새로운 것 배우기

무엇부터 배워야 할지 모를 때는 **학습 계획**부터 부탁하세요.

```text wrap
저는 60대이고 스마트폰 사진 정리를 배우고 싶어요. 매일 10분씩 일주일 동안 배울 계획을 짜 주세요. 첫날 할 일부터 자세히 알려 주세요.
```

## 아이 숙제 도와줄 때

아이 숙제를 AI에게 **대신 풀게 하면** 아이가 배우는 것이 없습니다. 이렇게 쓰는 것이 좋습니다.

- **부모가 먼저 이해하기:** "초등 4학년 분수 나눗셈을 부모가 아이에게 설명하는 방법을 알려 주세요"
- **힌트만 받기:** "답은 알려 주지 말고, 아이가 스스로 풀 수 있게 힌트만 단계별로 주세요"
- **비슷한 문제 만들기:** "이 문제와 비슷한 연습 문제 3개를 만들어 주세요"

<Info>
  학교마다 AI 사용 규칙이 다릅니다. 과제에 AI를 써도 되는지 선생님께 먼저 확인하세요. 자세한 내용은 [저작권과 올바른 사용](/safety/copyright)에서 다룹니다.
</Info>

## 직접 해 보기

요즘 뉴스에서 들었는데 뜻을 잘 모르는 말 하나를 골라 이렇게 물어보세요.

```text wrap
"(모르는 말)"이 무슨 뜻인지 초등학생도 알아듣게 설명해 주세요. 비유를 하나 들어 주세요.
```
